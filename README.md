# Fintlock marketing website

Production website for Fintlock, deployed to `https://fintlock.com` through GitHub Pages from `main`.
Plain HTML, CSS, and JavaScript. No frameworks, no trackers.

## How the site is built

Every page is generated by `build.py`. Edit the sources, then run:

```
python3 build.py
```

| Source | What it holds |
| --- | --- |
| `build.py` | Shared chrome (head, floating nav, footer, call to action), the Work, Services, Contact, Privacy and 404 pages, structured data, sitemap, and the version stamp |
| `service_pages.py` | Content for the four service landing pages |
| `_src/home.html` | Homepage body |
| `_src/tv.html` | TV SmartHub page body (`custom-tv-home-screen.html`) |
| `site.css` | The whole design system (light and navy skins) |
| `site.js` | Theme switch, mobile menu, TV screen tabs, live App Store details, contact form, 404 lock game, console note |

`_src/` starts with an underscore, so GitHub Pages (Jekyll) does not publish it.

## Features

- **Light / navy switch** in the nav. Remembered per visitor; applied before first paint to avoid a flash.
- **Live App Store details** for Plants in Pocket (version, last update, price, star rating and number of ratings), fetched from Apple's public lookup API and cached for 6 hours.
- **Contact form** posts to FormSubmit (`formsubmit.co`) and lands in contact@fintlock.com. Each note includes the page the visitor came from. If sending fails, the visitor gets a prepared email instead.
- **Version stamp** in every footer (`vYYYY.MM.DD-hash`), also in `<meta name="fintlock-version">` and `version.json`. The hash comes from the build inputs, so it changes whenever the site does.
- **404 lock game** at any missing URL, with a best time saved in the browser.
- **Console note** for developers who open the browser tools.

## Content constraints

- Use official Fintlock assets only.
- Do not add fabricated statistics, testimonials, clients, or results.
- Do not use em dashes, emojis, or buzzword filler in site copy.
- Keep claims specific and supportable. TV screenshots show sample scores and say so.
